# Текст сайта в Word

Небольшой веб-сервис: принимает ссылку на раздел публичного сайта, обходит внутренние ссылки, находит страницы, похожие на статьи, и сохраняет каждую найденную статью в отдельный `.docx`.

Для `kultprofita.ru/lenta/materials` используется публичная пагинация сайта и публичный текст материалов: это позволяет получить список целиком, а не только первые карточки страницы. Обработка выполняется пакетами с ограниченным параллелизмом; DOCX и ZIP создаются потоково на диске, чтобы большие выгрузки не исчерпывали память.

## Запуск

Нужен Node.js 20 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000` и вставьте ссылку на раздел со статьями. Выберите количество либо `Макс. — все найденные`. Можно задать даты публикации: если указана только начальная дата, конечной считается сегодняшняя. Результат скачивается ZIP-архивом с папкой по домену; в ней каждая статья находится в отдельном `.docx`. Сначала распакуйте ZIP, затем открывайте DOCX в Word.

Во время сбора интерфейс показывает число найденных статей и проверенных страниц. После обхода отображается прогресс подготовки DOCX-файлов и упаковки ZIP.

## Ограничения

- Обрабатываются публичные HTML-страницы. Ссылка на раздел должна содержать обычные ссылки на статьи; контент, который появляется только после выполнения JavaScript, может не обнаружиться.
- Парсер следует правилам `robots.txt`, делает паузы между запросами и не покидает исходный сайт. Режим `Макс.` обходит до 10 000 страниц за один запуск; общий объём извлечённого текста ограничен 100 МБ.
- Для фильтра по датам сайт должен публиковать дату в разметке страницы (например, `datePublished` или `time`). Статьи без распознанной даты пропускаются, когда задан период, и учитываются в уведомлении после выгрузки.
- Картинки из текста статьи встраиваются в конец документа (до 8 на статью); WebP/AVIF преобразуются в PNG, SVG пока пропускается.
- Максимальный размер HTML — 5 МБ; ожидание ответа — до 15 секунд.
- Разрешены только HTTP/HTTPS и стандартные порты. Локальные/приватные адреса и перенаправления на них блокируются.
- Парсер не обходит авторизацию, платный доступ, CAPTCHA или другие ограничения. Используйте его только для материалов, которые разрешено сохранять и обрабатывать.
